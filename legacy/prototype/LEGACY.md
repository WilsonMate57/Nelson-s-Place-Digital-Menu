# Legacy prototype (reference only)

The original static HTML/Bootstrap prototype, moved here unchanged on 2026-10-09 when the
real application was built (an identical copy is in `nelsons-place-menu-base.zip` at the
project root). It is not built, served or tested. Its branding, copy, data-model notes
(`docs/DATA-MODEL.md`) and plan (`docs/IMPLEMENTATION-PLAN.md`) informed the new
implementation; FR/ES UI strings in `assets/js/i18n.js` were not carried over because they
are unverified.
